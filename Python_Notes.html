1. Introduction to Python

Python is a high-level, general-purpose programming language created by Guido van Rossum and first released in 1991. "High-level" means it is written in a way that is close to human language, so you don't have to worry about the low-level details a computer's hardware deals with (like memory addresses). This makes Python one of the easiest languages for beginners to pick up, while still being powerful enough to run some of the largest software systems in the world.

Python is used across many fields: web development (Django, Flask), data science, automation and scripting, software testing, and — most importantly for your goals — Machine Learning and Artificial Intelligence, where it is the dominant language.

1.1 Why Learn Python?

  • Readable syntax: Python code reads almost like plain English, which reduces the learning curve.
  • Free and open source: Anyone can download, use, and contribute to Python at no cost.
  • Huge ecosystem for Machine Learning and AI: libraries such as NumPy, Pandas, Matplotlib, Scikit-learn, TensorFlow, and PyTorch are all Python-based.
  • Massive community: millions of developers worldwide, so help is always available online (Stack Overflow, official docs, forums).
  • Versatile: the same language can build websites, automate tasks, analyze data, and train AI models.

1.2 Installing Python

To start writing Python code, you first need the Python interpreter installed on your computer. The interpreter is the program that reads your Python code and executes it line by line.

  • Go to python.org and download the latest stable version for your operating system.
  • During installation on Windows, make sure to check the box that says "Add Python to PATH" — this lets you run Python from any terminal window.
  • After installation, open your terminal (Command Prompt, PowerShell, or Terminal on Mac/Linux) to confirm it worked.
PYTHON
# Check that Python is installed and see its version:
python --version

# Open the interactive Python interpreter (a live coding console):
python

# Inside the interpreter you can type code directly, e.g.:
>>> print("Hello, World!")
Hello, World!

1.3 Choosing an Editor

While you can write Python in any plain text editor, a proper code editor makes learning much faster because it highlights syntax, points out errors, and helps auto-complete code.

💡 Recommended Tools:

VS Code is a free, lightweight, and beginner-friendly editor with excellent Python support. Jupyter Notebook is especially popular for Machine Learning because it lets you run code in small, testable chunks called "cells" and see results (including charts) immediately below each cell.

1.4 Your First Program

Every programmer's first program traditionally prints "Hello, World!" to the screen. In Python, this takes just one line, which shows how beginner-friendly the language is compared to many others.

PYTHON
print("Hello, World!")

# Output:
# Hello, World!

The print() function is a built-in Python function whose job is to display whatever is inside its parentheses on the screen. You will use it constantly, especially while learning, to check what your code is doing.

2. Variables and Data Types

A variable is simply a named container that holds a value in the computer's memory, so you can refer to that value later using its name instead of retyping it. In Python, you create a variable simply by writing a name, an equals sign (=), and the value you want to store — there is no need to declare the data type in advance, unlike languages such as Java or C++. Python automatically figures out the type based on the value you assign.

PYTHON
name = "Huzaifa"       # a string (text) value
age = 21                 # an integer (whole number)
height = 5.9             # a float (decimal number)
is_student = True        # a boolean (True or False)

print(name, age, height, is_student)
# Output: Huzaifa 21 5.9 True

2.1 Rules for Naming Variables

  • Names can contain letters, digits, and underscores, but cannot start with a digit (e.g. age1 is valid, 1age is not).
  • Names are case-sensitive, meaning Age and age are treated as two completely different variables.
  • Avoid Python's reserved keywords (like print, if, for) as variable names.
  • Use descriptive names — student_name is clearer than a single letter like x.

2.2 The Core Data Types

Every value in Python belongs to a data type, which tells Python what kind of operations are valid on that value (for example, you can do math on numbers but not directly on plain text).

2.3 Checking and Converting Types

Sometimes you need to know a value's type, or convert a value from one type to another — for instance, turning text typed by a user into a number so you can do math with it. Python provides simple built-in functions for this.

PYTHON
x = 10
print(type(x))            # <class 'int'>

y = str(x)                 # convert int to string -> '10'
z = float(x)                # convert int to float -> 10.0
w = int("25")               # convert string to int -> 25

print(y, z, w)

3. Operators

Operators are special symbols that perform operations on values (called operands). Python groups operators into several categories, and understanding each one is essential for writing any logic.

3.1 Arithmetic Operators

These perform mathematical calculations, just as you'd expect from ordinary math, with two additions unique to programming: floor division and modulus.

PYTHON
a = 10
b = 3

print(a + b)     # Addition        -> 13
print(a - b)     # Subtraction     -> 7
print(a * b)     # Multiplication  -> 30
print(a / b)     # Division        -> 3.333...
print(a // b)    # Floor Division  -> 3  (rounds down, drops decimals)
print(a % b)     # Modulus         -> 1  (the remainder after division)
print(a ** b)    # Exponent/Power  -> 1000  (10 to the power of 3)

3.2 Comparison Operators

These compare two values and always produce a boolean result: True or False. They are the backbone of decision-making in code.

PYTHON
print(10 > 5)      # True   (greater than)
print(10 < 5)      # False  (less than)
print(10 == 10)    # True   (equal to)
print(10 != 5)     # True   (not equal to)
print(10 >= 10)    # True   (greater than or equal to)
print(10 <= 5)     # False  (less than or equal to)

3.3 Logical Operators

Logical operators combine multiple boolean conditions into a single True/False result, letting you build more complex decisions.

PYTHON
x = True
y = False

print(x and y)    # False -> both must be True
print(x or y)     # True  -> at least one must be True
print(not x)      # False -> reverses the value

3.4 Assignment Operators

Besides the basic = sign, Python offers shorthand operators that update a variable's value in place.

PYTHON
count = 5
count += 1     # same as: count = count + 1  -> 6
count -= 2     # same as: count = count - 2  -> 4
count *= 3     # same as: count = count * 3  -> 12

4. Input and Output

A program is only useful if it can communicate with the user. Python gives you print() to display output and input() to collect what the user types.

PYTHON
name = input("What is your name? ")
print("Welcome,", name)

# input() ALWAYS returns text (a string), even if the user types a number,
# so convert it before doing math with it:
age = int(input("How old are you? "))
print("Next year you will be", age + 1)
⚠ Common Beginner Mistake:

Forgetting that input() returns a string will cause errors like trying to add 1 to text. Always wrap it with int() or float() when you expect a number.

5. Conditional Statements

Conditional statements let your program make decisions and run different code depending on whether a condition is True or False. Python uses if, elif (short for "else if"), and else to build these decisions.

PYTHON
marks = 85

if marks >= 90:
    print("Grade: A+")
elif marks >= 75:
    print("Grade: A")
elif marks >= 50:
    print("Grade: B")
else:
    print("Fail")

# Python checks each condition top to bottom and runs the FIRST
# block whose condition is True, then skips the rest.
💡 Very Important — Indentation:

Unlike languages that use curly braces { }, Python uses indentation (spacing, usually 4 spaces) to define which lines belong inside a block. Incorrect indentation will cause an IndentationError, so always be consistent.

6. Loops

Loops let you repeat a block of code multiple times without rewriting it, which saves effort and avoids mistakes. Python has two main types: for loops and while loops.

6.1 The For Loop

A for loop is used when you want to repeat an action a specific number of times, or once for every item in a collection (like a list). The range() function generates a sequence of numbers to loop over.

PYTHON
for i in range(1, 6):     # generates 1, 2, 3, 4, 5 (stops before 6)
    print("Number:", i)

fruits = ["apple", "banana", "mango"]
for fruit in fruits:       # loops once for each item in the list
    print(fruit)

6.2 The While Loop

A while loop keeps repeating as long as its condition stays True. It is useful when you don't know in advance exactly how many times you need to repeat — the loop stops on its own once the condition becomes False.

PYTHON
count = 1
while count <= 5:
    print("Count:", count)
    count += 1     # without this line, the loop would run forever!

6.3 Break and Continue

Sometimes you need finer control inside a loop. break immediately exits the loop entirely, while continue skips just the current iteration and moves to the next one.

PYTHON
for i in range(1, 10):
    if i == 5:
        break        # stops the loop completely when i reaches 5
    if i % 2 == 0:
        continue     # skips even numbers, doesn't print them
    print(i)

# Output: 1, 3

7. Strings

A string is a sequence of characters — essentially, any piece of text — written inside single or double quotes. Python treats strings as ordered sequences, which means every character has a position (called an index), starting from 0.

PYTHON
text = "Python Programming"

print(text.upper())              # PYTHON PROGRAMMING
print(text.lower())              # python programming
print(text.replace("Python", "Java"))   # Java Programming
print(text.split())              # ['Python', 'Programming']
print(len(text))                 # 19 (total number of characters)
print(text[0])                   # 'P' (first character, index 0)
print(text[0:6])                 # 'Python' (slicing: characters 0 to 5)

String slicing, shown above with text[0:6], lets you extract a portion of a string by specifying a start index and an end index (the end index itself is not included). This is one of the most frequently used string techniques in Python.

7.1 f-Strings (Formatted Strings)

f-strings are a modern and highly readable way to insert variable values directly inside text, by placing an f before the opening quote and wrapping variables in curly braces.

PYTHON
name = "Huzaifa"
age = 21
print(f"My name is {name} and I am {age} years old.")
# Output: My name is Huzaifa and I am 21 years old.

8. Lists

A list is an ordered, changeable (mutable) collection that can hold multiple values of any type in a single variable. Lists are one of the most commonly used data structures in Python because of their flexibility.

PYTHON
numbers = [10, 20, 30, 40]

numbers.append(50)          # adds 50 to the end -> [10, 20, 30, 40, 50]
numbers.remove(20)          # removes the value 20 -> [10, 30, 40, 50]
numbers[0] = 100            # updates the item at index 0 -> [100, 30, 40, 50]

print(numbers)
print(len(numbers))         # total number of items in the list
print(numbers[1:3])         # slicing: items at index 1 and 2
print(sorted(numbers))      # returns a new, sorted list

Because lists are mutable, you can change, add, or remove their contents after creation — this is different from strings and tuples, which cannot be changed once created.

9. Tuples and Sets

9.1 Tuples

A tuple is very similar to a list — it is also an ordered collection — but once created, it is immutable, meaning its contents cannot be changed. Tuples are typically used for data that should stay constant, such as fixed coordinates.

PYTHON
coordinates = (10, 20)
print(coordinates[0])   # 10

# coordinates[0] = 99   # This would cause an error - tuples can't be changed

9.2 Sets

A set is an unordered collection that automatically removes duplicate values, making it useful whenever you need to guarantee that every item in a collection is unique.

PYTHON
colors = {"red", "blue", "red", "green"}
print(colors)   # {'red', 'blue', 'green'}  (duplicate 'red' is removed automatically)

10. Dictionaries

A dictionary stores data as key–value pairs, similar to a real dictionary where a word (the key) maps to its definition (the value). Dictionaries are extremely useful for representing structured, real-world information.

PYTHON
student = {
    "name": "Huzaifa",
    "age": 21,
    "course": "Machine Learning"
}

print(student["name"])          # access a value using its key -> Huzaifa
student["age"] = 22              # update an existing key's value
student["city"] = "Hazro"        # add a brand-new key-value pair

for key, value in student.items():   # loop through every key and value
    print(key, ":", value)

11. Functions

A function is a reusable, named block of code designed to perform a specific task. Functions let you write logic once and reuse it as many times as needed, which keeps code organized and avoids repetition.

PYTHON
def greet(name):          # 'def' defines a new function named greet
    return "Hello, " + name    # 'return' sends a value back to the caller

print(greet("Huzaifa"))   # calling the function with an argument
# Output: Hello, Huzaifa

def add_numbers(a, b=10):    # b=10 is a default value, used if none is given
    return a + b

print(add_numbers(5))        # 15  (uses the default b=10)
print(add_numbers(5, 20))    # 25  (overrides the default)

The parameters inside the parentheses (name, a, b) act as placeholders for the values, called arguments, that you pass in when you actually call the function. This separation lets the same function work with many different inputs.

12. Modules and Libraries

A module is simply a file containing pre-written Python code — functions, variables, and more — that you can bring into your own program using the import keyword, instead of writing everything from scratch. A library is a larger collection of related modules bundled together.

PYTHON
import math
print(math.sqrt(16))     # 4.0  (square root, from the math module)

import random
print(random.randint(1, 10))    # a random whole number between 1 and 10
💡 Important for Machine Learning:

As you move forward into Machine Learning, you will rely heavily on external libraries such as NumPy (numerical computations), Pandas (data handling and analysis), Matplotlib (data visualization), and Scikit-learn (ready-made ML algorithms). All of these are used through this exact same import mechanism, so mastering it now will pay off directly.

13. Exception Handling

Even correct-looking code can fail at runtime — for example, if a user types text where a number was expected. Exception handling, using try and except, lets your program catch these errors gracefully instead of crashing.

PYTHON
try:
    num = int(input("Enter a number: "))
    result = 10 / num
    print(result)
except ZeroDivisionError:
    print("You cannot divide by zero!")
except ValueError:
    print("Please enter a valid number!")

Python first attempts to run the code inside the try block. If an error occurs, it immediately jumps to the matching except block instead of stopping the entire program, which is essential for building reliable, user-friendly software.

14. File Handling

Programs frequently need to save data permanently or read data that already exists on disk. Python's built-in open() function, combined with the with statement, provides a safe and simple way to work with files.

PYTHON
# Writing to a file
with open("data.txt", "w") as file:   # 'w' mode = write (overwrites existing content)
    file.write("Hello Python!")

# Reading from a file
with open("data.txt", "r") as file:   # 'r' mode = read
    content = file.read()
    print(content)

Using with open(...) as file: automatically closes the file for you once the block finishes, even if an error occurs — this prevents data corruption and is considered the standard, safe way to handle files in Python.

15. Object-Oriented Programming (Basics)

Object-Oriented Programming (OOP) is a programming style that models real-world things as "objects," each combining data (attributes) and behavior (methods) together. A class is a blueprint for creating objects, and __init__ is a special method that runs automatically whenever a new object is created, used to set up its initial data.

PYTHON
class Student:
    def __init__(self, name, age):    # constructor: runs when a Student is created
        self.name = name                # 'self' refers to this specific object
        self.age = age

    def introduce(self):                # a method: behavior belonging to the object
        print(f"My name is {self.name} and I am {self.age} years old.")

s1 = Student("Huzaifa", 21)      # creating an 'object' (an instance of the class)
s1.introduce()
# Output: My name is Huzaifa and I am 21 years old.

OOP becomes especially useful as programs grow larger, because it groups related data and functionality together, making code easier to organize, reuse, and maintain — a pattern you will also encounter inside Machine Learning libraries like Scikit-learn.

  • Build small beginner projects to combine multiple concepts: a calculator, a to-do list, or a number-guessing game.
  • Once these fundamentals feel solid, move on to NumPy and Pandas — these two libraries form the practical foundation of Machine Learning work.
  • Don't fear errors — Python's error messages are usually clear and descriptive; read them carefully, as they are one of the fastest ways to learn.

Once these basics are comfortable, begin learning NumPy (for fast numerical computation with arrays) and Pandas (for loading, cleaning, and analyzing data). These two libraries are the true starting point of your Machine Learning journey.
